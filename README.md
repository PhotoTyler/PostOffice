# PostOffice

A Paper **26.2** plugin: write letters, pack parcels, post them at a public drop-off, and a
**Postman villager** physically walks them to the recipient's mailbox. Kill the Postman and his bag
spills on the floor.

## Features

| | |
|---|---|
| **Letter** | Paper + Black Dye. Write in it like a Book & Quill. Sneak + right-click to attach **one** item (no stacks, shulkers or bundles) and change the sender name. Posting seals it into an envelope. |
| **Reading** | Right-click a received letter: shows the text (click to read as a book) and the attached item; click the item to take it. The opened letter stays in your inventory. |
| **Parcel** | Planks / sticks / wheat in a ring with any item stack in the middle (up to a full stack), or an **Empty Box** + a stack. The ring without a centre item makes an Empty Box. |
| **Opening a parcel** | Place it on the ground, right-click: the flaps swing open and the contents float up. Right-click again to take them and get the Empty Box back. Breaking it drops both. |
| **Mailboxes** | UK wall box (iron + red dye + chest) or US standing box (iron + blue dye + chest). Place as many as you like and name them (anvil-rename the item, or sneak + right-click the box). Unlimited storage, can't be opened like a chest; right-click empties it straight into your inventory. A floating **New Mail!** sign shows while mail is waiting. |
| **Drop-off postbox** | Public red pillar box (red dye + iron + chest). Right-click with a letter/parcel → pick a player → pick their mailbox → **Send**. |
| **Postman** | Spawns at the drop-off after a few seconds, walks to each mailbox (hopping past obstacles, "taking the post road" for long or cross-world trips), messages the recipient "Hi, I've just delivered your mail". Right-click him for a chat. Only players can hurt him; killing him drops everything he carries. |

Mail survives restarts (`plugins/PostOffice/data/`): queued mail is sent out again, and undeliverable
mail goes back to the sender's mailbox or pocket.

## Commands

`/postoffice` (`/post`, `/mail`): `help`, `list`, `pack`, `items` (a creative-style menu of every
PostOffice item, for players in creative mode or with `postoffice.items`; Minecraft's own creative
tabs can't be changed by plugins), and for ops `give <item> [player] [amount]`,
`reload`, `status`.

Permissions: `postoffice.use`, `postoffice.place.mailbox`, `postoffice.place.dropoff` (all default
true), `postoffice.admin` (op).

## Building

```
./gradlew build
```

- `build/libs/PostOffice-1.0.0.jar` → put in your server's `plugins/` folder
- `build/PostOffice-pack.zip` → the texture pack

The textures and models are generated by `tools/generate_pack.py` (original pixel art, standard
library only) into `resourcepack/`; edit and re-run it to change them.

## Texture pack hosting

Every push to `main` builds the pack and publishes it to GitHub Pages. The default `resource-pack.url` (`https://phototyler.github.io/PostOffice/PostOffice-pack.zip`) points there; change it in
`plugins/PostOffice/config.yml` if you host the pack somewhere else. The plugin downloads
the pack at startup and on `/postoffice reload` to work out its SHA-1 itself, so after updating the
pack you only need `/postoffice reload`.
