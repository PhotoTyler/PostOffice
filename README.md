# PostOffice

A Paper **26.2** plugin: write letters, pack parcels, post them at a public drop-off, and a
**Postman villager** physically walks them to the recipient's mailbox. Kill the Postman and his bag
spills on the floor.

## Features

| | |
|---|---|
| **Letter** | Paper + Ink Sac. Write in it like a Book & Quill, but there's no signing: the pack renames the **Sign** button to **Put in envelope** (and the title box to the name on the envelope), and the plugin seals the letter instead. Right-click an envelope to open it (it shows as a book), then change it and reseal it. Sneak + right-click a letter to attach **one** item (no stacks, shulkers or bundles). The renamed button text shows on every Book & Quill; ordinary books still sign normally. |
| **Boxes & parcels** | Craft an Empty Box (planks / sticks / wheat ring). Pack it by crafting it in the middle of up to 8 item stacks, or place it on the ground and right-click it with items (empty hand takes the last one out, sneak + right-click seals it; a "Box full" sign shows at 8 stacks). No shulker boxes, bundles or other mail. Breaking a sealed box drops the parcel; breaking an open one drops the box and items separately. |
| **Opening a parcel** | Place it and right-click: the flaps swing open and the contents float up, taking turns. Take items out with an empty hand. |
| **Mailboxes** | UK wall box (iron + red dye + chest) or US standing box (iron + blue dye + chest). Place as many as you like and name them (anvil-rename the item, or sneak + right-click the box). Unlimited storage, can't be opened like a chest; right-click empties it straight into your inventory. A floating **New Mail!** sign shows while mail is waiting. |
| **Drop-off postbox** | Public red pillar box, two blocks tall (red dye + iron + chest). Right-click with a sealed letter or parcel → pick a player → pick their mailbox → **Send**. Parcels start unnamed and must be named first (the name tag button: [Use my name] or type any name). The Postmaster can change the "from" name on a held letter or parcel too. |
| **Postman** | Appears out of sight near the drop-off, walks over and collects the mail (waiting 5 seconds), then walks to each mailbox within 50 blocks (opening doors, hopping if stuck). For further mailboxes he walks until nobody can see him, vanishes, and reappears out of sight near the mailbox. Waits 5 seconds at each mailbox, then walks off and vanishes out of view. Messages the recipient "Hi, I've just delivered your mail". Right-click him for a chat. Only players can hurt him; killing him drops everything he carries. |
| **Post Offices** | Every village gets a small Post Office (styled for plains, desert, savanna, taiga and snowy villages) with a public drop-off and a **Postmaster** who trades. Villages that already exist get one the first time they load. |
| **Village Postmen** | An unemployed villager next to a drop-off takes the job: uniform, cap, and all the postal trades (paper, ink sacs, letters, boxes, mailboxes for emeralds and back; editable in `config.yml`). Ordinary nitwits wear the uniform too (no cap) and each trades a random 3-5 of them, so trading still works if the Postmaster is gone. |
| **Uniform** | The resource pack restyles the **nitwit** villager outfit as the postal uniform, so all nitwits wear it. Set `postman.profession` to another profession to avoid that. |

Mail survives restarts (`plugins/PostOffice/data/`): queued mail is sent out again, and undeliverable
mail goes back to the sender's mailbox or pocket.

## Commands

`/postoffice` (`/post`, `/mail`): `help`, `list`, `pack`, `items` (a creative-style menu of every
PostOffice item, for players in creative mode or with `postoffice.items`; Minecraft's own creative
tabs can't be changed by plugins), and for ops `give <item> [player] [amount]`,
`reload`, `status`.

Permissions: `postoffice.use`, `postoffice.place.mailbox`, `postoffice.place.dropoff` (all default
true), `postoffice.admin` (op).

## Building

```
./gradlew build
```

- `build/libs/PostOffice-1.8.0.jar` → put in your server's `plugins/` folder
- `build/PostOffice-pack.zip` → the texture pack

The textures and models are generated by `tools/generate_pack.py` (original pixel art, standard
library only) into `resourcepack/`; edit and re-run it to change them.

## Texture pack hosting

Every push to `main` builds the pack and publishes it to GitHub Pages. It is also pushed to the `pack` branch, and the default `resource-pack.url` (`https://raw.githubusercontent.com/PhotoTyler/PostOffice/pack/PostOffice-pack.zip`) points there, because some hosts (MineKeep) only allow packs from raw.githubusercontent.com; change it in
`plugins/PostOffice/config.yml` if you host the pack somewhere else. The plugin downloads
the pack at startup and on `/postoffice reload` to work out its SHA-1 itself, so after updating the
pack you only need `/postoffice reload`.
